## Как запустить локально

Файл не требует сервера — достаточно открыть `index.html` в браузере:

```bash
git clone https://github.com/marmellion/SciComm_Almeo.git
cd SciComm_Almeo
open index.html   # на Windows: start index.html
```

## Деплой на GitHub Pages

1. Репозиторий → **Settings → Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `main`, папка `/ (root)`
4. Сохранить — через 1–2 минуты сайт появится по адресу вида `https://<username>.github.io/<repo>/`

Важно: файл в корне репозитория должен называться именно `index.html` — иначе GitHub Pages не найдёт точку входа и вместо сайта будет показывать README или отдавать 404.
